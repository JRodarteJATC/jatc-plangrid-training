# Glossary – Roofing, Waterproofing & Plan Software

| Term | Definition |
|---|---|
| **AFF** | Above Finished Floor. |
| **Area divider** | A raised curb or break dividing a roof into areas; used as a high point and for phasing. |
| **As-built** | Markups showing what was actually installed when it differs from the design. |
| **ASI** | Architect's Supplemental Instruction – a minor change issued by the design team. |
| **Ball in court** | Who is responsible for the next action on an RFI, submittal or issue. |
| **Base flashing** | Membrane turned up a wall/curb; typically 8" min above the finished roof. |
| **Blindside waterproofing** | Membrane installed *before* concrete is poured against it (pre-applied). |
| **BUR** | Built-up roof – multiple plies of felt and asphalt. |
| **Calibrate** | Tell the software how many screen units equal a real distance. |
| **Callout** | Symbol pointing to a detail on another sheet (e.g. 2 / R-501). |
| **Clamping ring** | Ring on a roof drain that clamps the membrane to the drain body. |
| **Closeout** | End-of-job turnover: as-builts, warranties, O&M, punch complete. |
| **Coping** | Sheet-metal cap on top of a parapet. |
| **Counterflashing** | Metal that covers the top of base flashing to shed water. |
| **Cover board** | Thin, dense board over insulation to protect it and give the membrane a solid base. |
| **Cricket / saddle** | Small sloped area that diverts water around curbs or between drains. |
| **CSI MasterFormat** | Standard spec numbering. Division 07 = Thermal & Moisture Protection. |
| **Daily report** | The job's daily record of weather, manpower, work, delays and safety. |
| **Delta (△)** | Triangle with a number marking a revision. |
| **Drainage composite** | Dimpled plastic core + filter fabric that carries water to the footing drain. |
| **Fishmouth** | Wrinkle/opening at a membrane lap – a leak point. |
| **Flood test** | Filling a waterproofed area with water (e.g. 24 hrs) to prove it doesn't leak. |
| **Hydrophilic waterstop** | Strip at concrete joints that swells when wet to block water. |
| **Issue** | A tracked problem or to-do pinned to a location. PlanGrid called these Tasks. |
| **JHA / Pre-task plan** | Job Hazard Analysis – steps, hazards and controls reviewed before work. |
| **Low line / valley** | Lowest line of the roof where drains are located. |
| **Markup** | Any drawing/annotation added on top of a sheet. |
| **NDL warranty** | No Dollar Limit manufacturer warranty – covers repairs regardless of cost. |
| **Night seal / tie-in** | Temporary seal at the end of the day so water can't get under new roofing. |
| **NTS** | Not To Scale – do not measure. |
| **Overflow drain / scupper** | Secondary drainage if primary drains clog; set higher than primary. |
| **Overlay / Compare** | Two versions of a sheet on top of each other to spot changes. |
| **Parapet** | Wall extending above the roof edge. |
| **Personal / Published** | Markup visibility: only you vs. the whole team. |
| **Polyiso** | Polyisocyanurate rigid foam insulation board. |
| **Protection board** | Board over below-grade membrane to protect it during backfill. |
| **Punch list** | Incomplete or defective work to finish before closeout. |
| **RFI** | Request for Information – formal question to the design team. |
| **Revision cloud** | Scalloped outline around a changed area. |
| **RTU** | Rooftop unit (HVAC), set on a curb. |
| **SBS** | Styrene-butadiene-styrene modified bitumen membrane. |
| **Seam probe** | Blunt tool dragged along welded seams to find voids. |
| **Square** | 100 square feet of roof. |
| **Submittal** | Product data, shop drawings or samples sent for approval before purchase. |
| **Sump** | Recessed area of insulation around a drain. |
| **Tapered insulation** | Insulation cut at a slope (e.g. 1/4":12") to create roof drainage. |
| **Termination bar** | Metal bar fastened through the top edge of flashing to hold it tight. |
| **Title block** | Sheet area with project info, sheet number, title, scale and revisions. |
| **TPO** | Thermoplastic polyolefin single-ply membrane, heat-welded seams. |
| **Vapor retarder** | Layer that slows moisture moving up from the building into the roof. |
| **Version set** | A group of sheets issued together under one name/date. |
| **Walkway pad** | Protective pad welded to the membrane along service routes. |
| **Warning line** | Rope/flag line set back from roof edges (OSHA 1926.502(f)). |
